# ClockHandKit

WidgetKit clock hand rotation effect — works on Xcode 26.1+.

A pure-source Swift Package replacement for [`octree/ClockHandRotationKit`](https://github.com/octree/ClockHandRotationKit).

## Usage

```swift
import ClockHandKit

Image(systemName: "arrow.up")
    .clockHandRotationEffect(period: .secondHand)
```
